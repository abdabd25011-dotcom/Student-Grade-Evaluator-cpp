# Student Grade Evaluator (C++)

A simple console application written in **C++** that evaluates a student's numerical mark and outputs the corresponding academic grade.

## Features
- Validates user input to reject non-numeric characters.
- Checks that the entered mark is within the valid range (`0` to `100`).
- Classifies marks into standard academic tiers (`Excellent`, `Very Good`, `Good`, `Medium`, `Pass`, `Fail`).

## How to Run
1. Compile the source code using any C++ compiler (e.g., `g++`):
   ```bash
   g++ main.cpp -o grade_evaluator
